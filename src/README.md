# src

解析パイプラインを実装する Python package `mawi_global_analysis` を置くディレクトリです。

flow 抽出、Aguri 実行、prefix/membership、scan statistics/labels、cache、manifest、batch
処理などの再利用可能な実装をここに置きます。実験ごとの YAML、Notebook、raw data、
run-specific artifact はここに置きません。

テストは [tests/](../tests/README.md)、リポジトリ全体の処理境界は
[ルート README](../README.md) を参照してください。
