実験条件

選定集合と selected_union

unionはflow_idを一意化。個別/24の合計ではありません。— は欠損または未定義を示します。

Coverageの分母は共通のOverall IPv4 TCP/UDPです。分母0の比率・両方空のJaccard・空分布を含むKSは未定義（—）。選定が空でも、分母が非0のcoverageは0です。

正確な分布統計とKS型距離

KS型距離は各selected_unionとOverallの最大ECDF差です。記述的な分布差であり、検定のp値ではありません。整数の分子/分母を併記します。

ブラウザは保存済みの統計値とcumulative_fractionを表示します。度数の再集計・coverage・KSの再計算は行いません。表示を削減した曲線は下界の階段と次の選択点による上界を示します。帯の内部の正確な段差は不明です。正確な度数はecdf_counts.csvおよびmodes/*/frequencies.csvから再現できます。

選択した/24の正確な分布統計

各/24内ではsrc OR dstに所属するflow_idを一意化しています。異なる/24には同じフローが所属し得ます。個別ECDFを混合・平均した図ではなく、それぞれの分布を独立に描きます。selected_unionは選定集合全体でflow_idを一意化した別の分布です。表示点を削減した場合、選択点は真値、中間の階段は下界、帯は上界です。全度数はmodes/<mode>/frequencies.csvに保持されます。

指標と母集団の定義

Overall
canonical IPv4 TCP/UDPフロー全体です。canonical src/dstは最初の観測方向であり、initiator/responderや通信の意図を意味しません。
Native / normalized /24
native選定prefixとnormalized /24は異なります。normalized /24では包含する/24全体のmembershipをsrc OR dstで再計算します。
/24 membership
1フローが複数の/24に所属する場合があります。個別/24統計を単純に合計してunion統計にできません。
selected_union
選定された/24のmembershipをflow_idで一意化した集合です。flow・packet・byte coverageの分子はこの集合の総量です。
RLS discounted count
HHHのdiscounted residual countは、実際のprefix所属フロー数ではありません。
ECDF
正確な整数度数を統合した、フロー数で重みづけられた右連続分布です。/24ごとのECDFの均等平均ではありません。
KS型距離
Overallとの最大ECDF差を表す記述統計量です。独立標本検定やp値として扱いません。
Packet / byte
packet_countとbyte_countは保存済みcanonical観測値です。byte_countはEthernetフレームの総量です。
Exact / displayed
総量と累積数は正確な整数文字列として表示します。対数軸の画面座標と比率の表示は浮動小数点です。縮約ECDFの選択点は実際の観測値ですが、中間の階段は下界です。
証拠の範囲
合成データやfixtureの検証は実装確認です。実MAWIデータでの本実験や科学的結論の証拠ではありません。
